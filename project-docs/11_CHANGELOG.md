## Versioning policy

- **MAJOR:** incompatible public API, data, or product behaviour.
- **MINOR:** backward-compatible feature.
- **PATCH:** backward-compatible fix, security patch, or documentation correction.

Record development-only work in `10_DEV_LOG.md`; promote it here when released or when this project’s release policy requires versioning.
