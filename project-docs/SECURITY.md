# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| [LATEST] | ✅ |
| [PREVIOUS] | ⚠️ Security fixes only |
| < [PREVIOUS] | ❌ |

## Reporting a vulnerability

**Do not open a public issue.**

Email: [SECURITY@EXAMPLE.COM] (or use the project's private disclosure channel).

Include:
- Description and impact.
- Steps to reproduce / proof of concept.
- Affected versions / environments.
- Any known mitigations.

## Response SLA

| Severity | Initial response | Fix target |
| --- | --- | --- |
| Critical | 24 hours | 72 hours |
| High | 48 hours | 14 days |
| Medium | 5 working days | 30 days |
| Low | 10 working days | Next release |

## Scope

This policy covers all repositories under this organisation. Out-of-scope: social engineering, DoS, third-party services.
