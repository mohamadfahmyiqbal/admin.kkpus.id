## 2. Temuan Keamanan (Security)

### 🔴 KRITIS

#### 2.1 Token JWT Tanpa Signature (alg: none)

**Lokasi:** `src/utils/helpers/index.js:1-25`

```javascript
const header = { alg: "none", typ: "JWT", ver: "1.0" };
return `${encode(header)}.${encode(data)}.`;
```

**Bukti:** JWT dibuat dengan `alg: "none"` — tidak ada signature kriptografis.

**Dampak:**
- Token dapat dipalsukan oleh siapa saja
- Tidak ada verifikasi integritas token
- Risiko privilege escalation (user bisa mengubah role/permission)
- Risiko akses data anggota lain

**Rekomendasi:**
1. Implementasikan JWT dengan signature (HS256/RS256)
2. Verifikasi signature di backend untuk setiap request
3. Gunakan library JWT yang aman (jsonwebtoken, jose)

---

#### 2.2 Penyimpanan Token di localStorage

**Lokasi:** `src/utils/api/common.js:18`, `src/App.jsx:15`, 17+ file lainnya

```javascript
const token = localStorage.getItem("token");
```

**Dampak:**
- Rentan terhadap XSS (Cross-Site Scripting)
- Token dapat dicuri via malicious script
- Tidak ada proteksi CSRF built-in

**Rekomendasi:**
1. Pindahkan token ke HttpOnly cookie
2. Implementasikan CSRF token
3. Tambahkan Content Security Policy (CSP) header

---

#### 2.3 Parsing JSON Tanpa Validasi dari localStorage

**Lokasi:** `src/components/modals/ProgramApprovalModal.jsx:41`, `src/components/layout/LayoutGlobal.jsx:13`

```javascript
return JSON.parse(localStorage.getItem("userData") || "{}");
```

**Dampak:**
- Jika localStorage dimanipulasi, aplikasi dapat crash
- Tidak ada fallback error handling
- Potensi injection jika data tidak divalidasi

**Rekomendasi:**
1. Bungkus dengan try-catch
2. Validasi struktur data sebelum digunakan
3. Gunakan schema validation (zod, yup)

---

#### 2.4 document.write() pada Print Function

**Lokasi:** `src/components/modals/TransactionDetailModal.jsx:38-99`

```javascript
printWindow.document.write(`...`);
```

**Dampak:**
- `document.write()` dapat membuka celah XSS jika ada user input
- Menghentikan parsing dokumen jika dipanggil async
- Praktik deprecated

**Rekomendasi:**
1. Gunakan DOM manipulation (createElement, appendChild)
2. Sanitize semua konten sebelum render
3. Gunakan library print-safe

#### 2.7 Sanitasi String Tidak Lengkap

**Lokasi:** `src/utils/helpers/sanitization.js:27-34`

```javascript

  return str
    .replace(/[<>]/g, "")
    .replace(/javascript:/gi, "")
    .replace(/on\w+=/gi, "")
    .trim();
```

**Dampak:**
